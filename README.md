# Readme

How to use the plugin
So first install the plugin it should say enabled or aktif edildi(enabled) and on config there are events that sends command automatically on event when the event is started the command is gonna sended. So the command prefix is (servercommand which is empty), (.) and (/)
/ means remote admin command
. means client command
So how does it work
it uses ExecuteCommand to send the command
